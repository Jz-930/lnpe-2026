# 应用与物料内容覆盖记录

实施日期：2026-10-15。对应根目录审阅方案 A01–A07、05《133项物料内容补齐表》及04《海外老站补充清单》的材料部分。

## 已完成范围

- 保留原应用页主视觉、工艺图和8张行业卡片；原物料标签变为低强调详情链接。
- 每张行业卡加入默认收起的双语“行业加工说明”，各3短段，分别说明原料差异、关键指标和工艺条件/路线取舍，并连接现有研究或工程资料。
- 原133个分类入口全部保留，新增本地文案3项与海外材料线索33项，共169个分类入口。
- 三七/田七以及化工/其他分类的氧化锌分别共用详情，最终167项独立材料说明。目录与统计明确区分“分类条目”与“材料说明”，不把数量写成完成试验的样品数。
- 每项有独立双语材料介绍和加工重点，配合16类按物性划分的工序解释、选型依据、送样输入、试验评价和实际设备/工艺链接。
- 新增目录 `/applications/materials`，支持中英文、正确别名/缩写、行业筛选及 `?q=` 预填搜索；新增详情 `/applications/materials/[slug]`。
- 全部133张原有物料图片接入详情。共131项有原图的材料实体；别名/跨分类合并记录保留多图。新增36项无确认图片时采用文字布局，不挪用其他材料图。
- 详情咨询入口携带 `material` 与 `service=trial`，通过现有联系页承接。

## 术语、别名和检索

- 硅碳复合使用Si/C，与碳化硅SiC为不同实体；硅氧碳复合使用SiO/C，未将SiOC陶瓷自动合并。
- 重写NCA定义，移除原稿套用LFP的错误；钠基磷酸盐说明不再混写锂电体系；Garnet、Slag等英文名称统一。
- 公共aliases不保留错误化学符号、明确误译或不成立的同义映射。特别移除“硅碳（SiC）”“Silicon carbon (SiC)”“硅氧（SiOC）”“Silicon oxygen (SiOC)”，以及雪松树皮→杉树皮、再生塑料→垃圾映射。
- 增补LFP、LMFP、NCA、NCM/NMC、LTO、SiC、Si/C、SiO/C、GCC、PCC、SAP、PAM、PPS、API等准确缩写。原错误名称仅在内部来源 `originalLabels` 中保留追溯。
- 材料目录使用名称/别名检索，不将正文中用于区分另一物料的化学符号当成本材料别名。

## 来源与编写边界

- 本地依据：审阅目录 `evidence_local/现站133物料补齐矩阵.json`、对应 `LNPE-应用领域.docx` 的段落定位、原站图像路径和审阅表；新增3项使用364–366、492–494、498–500段。
- 海外依据：04审阅清单及其已保存网页证据。旧站材料标题/通用设备说明只用于材料范围与候选设备线索，不改写为已验证专用方案。
- NCA、Si/C及钠基磷酸盐术语另保留Argonne、美国能源部及ORNL的公开参考来源。
- 独立材料介绍与加工重点经过编辑重写；通用单元操作说明为有条件的工艺起点，不是材料专用试验报告。未公开内部PPT参数、未创造粒度/产量/能耗或认证结果。
- 药材与食品内容不沿用原稿治疗功效或吸收率承诺。未明物料采用身份与适用性评估说明；没有因此承诺某种特殊物料必然可承接。
- 具体型号、气氛、温度、产能、收率、能耗、杂质、性能及特殊材料服务范围仍由真实来料试验和项目条件确定。页面有实际选型输入和咨询路径，不以空白占位代替内容。
